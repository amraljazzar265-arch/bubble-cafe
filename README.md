# Bubble Café — منيو

منيو رقمي تفاعلي لمقهى **Bubble Café** — صفحة واحدة، عربي (RTL)، بتأثيرات ثلاثية الأبعاد وتوهّج، مُحسّن للجوال.

## المحتوى
- `index.html` — الصفحة الكاملة (HTML + CSS + JS في ملف واحد)
- `logo/` — الشعار والأيقونات (favicons)
- `data/` — صور المنتجات
- `first enter.mp4` — فيديو المقدمة
- `hero2.jpg.jpeg` — خلفية الهيرو

## التشغيل
افتح `index.html` في المتصفح مباشرة، أو فعّل **GitHub Pages** للحصول على رابط مباشر يُفتح على أي جهاز.
