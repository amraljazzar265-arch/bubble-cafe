# Bubble Café — منيو

منيو رقمي تفاعلي لمقهى **Bubble Café** — صفحة واحدة، عربي (RTL)، بتأثيرات ثلاثية الأبعاد وتوهّج، مُحسّن للجوال.

## المحتوى

- `index.html` — الصفحة الكاملة (HTML + CSS + JS في ملف واحد)
- `assets/menu/` — صور المنتجات (WebP، ٤٠ صورة)
- `logo/` — الشعار والأيقونات (favicons)
- `hero-phone.webp` / `hero-phone.jpg` — خلفية الهيرو على الجوال (WebP + بديل JPEG)
- `hero-wide.webp` / `hero2.jpg.jpeg` — خلفية الهيرو على الشاشات الكبيرة

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو افتح الرابط المباشر عبر **GitHub Pages**.

## ملفات محلية غير منشورة

`data/` و `_originals/` و `assets/manifest.tsv` والصور الأصلية عالية الدقة موجودة على الجهاز فقط
(انظر `.gitignore`) — الموقع المنشور لا يحتاجها.
